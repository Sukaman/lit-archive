[19] DP's impact in US public schools serving low income communities (2020)：低收入社区公立学校中 IB 文凭项目的影响

IB 公立学校实证研究类 ｜ 研究报告 [R] ｜ 来源链接 ↗ ｜ 英文原文 ↗

【摘要报告（中译）】

本研究考察加州公立学校中 IB 文凭项目（DP）学生在高中与大学阶段的经历——这些学校主要服务低收入家庭学生，且这些学生所在社区几乎没有大学升学传统。在高中层面，研究比较了 DP 学生与非 DP 学生在参与度和动机上的差异；在大学层面，研究考察了 DP 与学生入学准备、学业成功和抗逆力的关系。研究发现：DP 学生修读更严谨的课程、动机更强、参与度更高；加州大学系统数据显示，参与 IB 与学生大学保留率以及五年、六年毕业率存在显著正向关联；DP 校友认为，该项目在写作、批判性思维、学习技能与时间管理方面为他们应对大学学业做了准备。

【引言：问题背景】

美国的低收入学生不成比例地来自非裔与拉丁裔青年群体（Gándara & Contreras, 2009；Rothstein, 2004）。虽然这两个群体只占美国儿童总数的三分之一，却占极度贫困社区青年的四分之三以上（O'Hare & Mather, 2003）。其结果是，贫困对代表性不足的少数族裔低收入学生的教育经历产生负面影响，使他们往往难以进入优质学校、难以获得平等机会。低收入的拉丁裔与非裔学生更可能就读于高度隔离的学校——这类学校人满为患、师资较弱、缺乏荣誉课程和 AP 课程等严谨的大学预修课程，整体教育资源也较少。

【文献综述：IB 文凭项目】

IB 文凭项目（IBDP）是面向 11、12 年级的严谨大学预科课程，由「DP 核心」与六个学科组构成（语言与文学、语言习得、个人与社会、科学、数学、艺术）。学生修读各学科内容课程，同时 DP 核心为他们拓宽理解、挑战知识应用提供空间。DP 核心含三要素：知识论（TOK）——反思知识的本质与「我们如何知道所声称知道的东西」；拓展论文（EE）——独立、自主的研究，以 4000 字论文收尾；创造、活动、服务（CAS）——学生完成创造性、体育活动与服务项目。

【研究目的与问题】

本研究考察加州公立学校中 DP 学生的中学与大学后经历——这些学校主要服务低收入家庭、且升学历史很短或无升学传统的学生。研究问题包括：（1）这些学校的 DP 学生如何描述他们在项目中的经历？哪些特征、结构与方面对他们最显著？他们在 IB 项目中在多大程度上接触到文化相关的课程？（2）DP 学生的学业表现与非 DP 同伴相比如何？（3）DP 学生在参与度与动机指标上表现如何？（4）大学阶段的结果如何——入学准备、坚持就读、毕业率等。

【研究设计】

为回答这些宽泛问题，研究采用嵌入式混合方法设计（Creswell, Plano & Clark, 2003），同时纳入定量与定性数据。研究对感知数据与结果数据进行定量分析，并用质性方法捕捉学生的声音与叙事。该设计的优势基于这样一个前提：单一数据集不足以理解 IBDP 对第一代和低收入学生的影响——要理解 IBDP 如何影响学生的生活，需要回答不同的问题，而每类问题需要不同类型的数据。为此，研究采用了多案例研究设计（Yin），聚焦加州三所服务低收入社区的大型公立高中。

【数据收集与分析】

定量数据来自加州大学系统的学生记录，样本规模约 21,967 人，其中 IB 学生约 670 人；分析比较完整 DP 学生、部分 DP 学生、IB 中学项目（MYP）学生与同伴群体在高中 GPA、大学入学、保留率与毕业率上的差异。定性数据来自对 DP 学生、校友、教师与校长的访谈，以及课堂观察与文件分析，用以呈现学生的主观经历与项目实施的细节。

【主要发现（一）：高中经历】

DP 学生报告说，他们经历了更严谨、更具挑战性的课程，并在课堂上形成更强的学习共同体意识。许多学生是家庭中第一代大学生，他们将 DP 视为通往大学的路径和「可行的选择」。教师与校长指出，DP 的严谨性对学生是挑战也是激励，但同时也提出，项目的学术要求与考试成本可能构成障碍。在参与度与动机上，DP 学生普遍高于非 DP 同伴，并对学校有更强归属感。

【主要发现（二）：大学结果】

加州大学系统的数据显示，IB 参与与多个积极结果显著相关：DP 学生的大学准备度更高；大学保留率与五年、六年毕业率更高。即使在控制种族、父母教育程度、高中 GPA 等变量后，IB 参与仍与更高的毕业率相关。作者强调，这些相关性并不简单等同于因果，但足以说明 IB 在高贫困学校中可能发挥「大学通道」的作用。

【主要发现（三）：校友视角】

DP 校友认为，项目在写作、批判性思维、学习技能与时间管理方面为他们适应大学学业做了充分准备。许多人提到 CAS 与拓展论文让他们发展了课堂之外的能力，TOK 则改变了他们思考知识的方式。部分校友还强调，IB 帮助他们建立了「可以进入大学并取得成功」的身份认同——这对来自低收入社区、缺乏大学升学传统的学生尤为重要。

【结论与启示】

研究表明，在低收入社区公立学校中，IB 文凭项目可以为学生提供严谨的课程与大学准备，并与更高的大学保留率和毕业率相关。对政策与实践的启示包括：应扩大低收入学校获取 IB 项目的机会；需关注项目成本与考试费用对弱势学生的障碍；应重视文化相关课程的设计，使项目内容与学生的生活经验相连接。作者同时指出研究局限——准实验设计无法完全确立因果关系，且结果来自加州特定学校，推广需谨慎。
